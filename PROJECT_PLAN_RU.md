# Текущая стадия работы

## Цель

Получить воспроизводимые положения астероида (7065) Fredschaaf относительно Gaia
и оценить фактическую повторяемость координат на серии коротких CCD-экспозиций.
Поиск слабого сигнала двойственности возможен только после устойчивого результата
на нескольких ночах с точностью заметно лучше первоначальных 100 mas.

## Целевой сигнал и Gaia FPR

В опубликованной таблице кандидатов Gaia DR3 для (7065) указаны:

- период колебания фотоцентра `94.864 ± 1.81 ч`;
- амплитуда проекции вдоль скана `8.05 ± 0.71 mas`.

Это не амплитуда по каждой из RA/Dec, а одномерная проекция Gaia.
Её нельзя напрямую сравнивать с двумерным RMS наземных координат.

Прямая выборка Gaia FPR для объекта содержит 556 CCD-измерений
в 79 транзитах. После штатных флагов остаются 443 измерения в 74
транзитах. Для хороших CCD-измерений медианная случайная ошибка равна
примерно `1.01 mas` вдоль скана (AL) и `612 mas` поперёк (AC).
Обратно-взвешенное объединение CCD даёт медианную ошибку AL транзита около
`0.48 mas` с учётом систематической компоненты.

Ошибки Gaia нужно проецировать из ковариации в `(RA·cos Dec, Dec)`. Если `C` -
ковариационная матрица, а `theta` - `position_angle_scan`, то
`u_AL = (sin(theta), cos(theta))` и `sigma_AL^2 = u_ALᵀ C u_AL`. Случайная
и систематическая матрицы считаются отдельно: случайная уменьшается при
объединении CCD одного транзита, а общая для транзита систематика - нет.

## Выполненные этапы

### 0. Единый формат Gaia FPR и наземных серий

- Добавлен воспроизводимый запрос FPR для номера 7065 и сохранение исходной
  таблицы без потери полей.
- Реализована полная ковариация `(RA·cos Dec, Dec)`, её проекция на AL/AC и
  раздельное объединение случайной и общей для транзита систематики.
- Реализовано объединение CCD-остатков только после вычисления орбитальной
  модели на каждой CCD-эпохе.
- Результат пулковской серии приведён к строке с UTC/JD, O−C и ковариацией.
- Подготовлена периодограмма общего двумерного синусоидального смещения через
  произвольные одномерные проекции, пригодная одновременно для Gaia AL и ξ/η.

FPR O−C вычисляются не приближённой кеплеровской эфемеридой, а распространением
опубликованного состояния с ASSIST. Согласованы TCB-эпохи и масштаб FPR-вектора
с TDB динамического интегратора, гелиоцентрическая и барицентрическая системы,
положение Gaia, световое время и релятивистское отклонение в поле Солнца. Для
наземной звёздной привязки используется дифференциальная поправка между
конечным расстоянием астероида и практически бесконечным расстоянием звёзд.
Вклад планет в отклонение света остаётся следующим уточнением суб-mas уровня.

### 0.1. Первая диагностическая сетка дисторсии

Каталог поля расширен до 680 Gaia-источников с `G ≤ 19.5`. Формально центры хотя
бы на части кадров находятся у 124 звёзд, но критерий повторяемости на уровне
не хуже 500 mas проходят только 57. Статистически поддерживается грубая сетка
`4 × 3`, в которой заполнены 11 ячеек.

Проверка теперь выполняется на девяти полностью исключённых из построения
Gaia-источниках, а не просто на других кадрах тех же звёзд. Медианный модуль их
усреднённого O−C равен `58.533 mas` до карты и `58.536 mas` после неё — улучшения
нет. Карту применять к астероиду нельзя. Нужны дизеринг/калибровочное поле,
более длинные экспозиции и больше устойчиво измеряемых опорных звёзд.

### 0.2. Первые FPR O−C и периодограмма

Скачаны JPL DE440 и kernel 16 массивных астероидов DE441. Опубликованный
гелиоцентрический FPR-вектор переводится в согласованный масштаб TDB,
добавляется барицентрическое состояние Солнца, после чего ASSIST распространяет
орбиту к моменту испускания света каждого CCD-наблюдения. Небольшое уточнение
шести начальных координат согласует опубликованную орбиту с несколько иной
силовой моделью ASSIST: после солнечного отклонения света робастный разброс
AL-остатков транзитов уменьшается с `4.44 mas` до `1.81 mas`.

В самом плотном FPR-окне имеются 15 транзитов за `4.326 суток`. Периодограмма по
методу статьи (средний AL-остаток транзита и его эмпирический CCD-разброс) даёт:

- глобальный максимум `45.935 ч`, амплитуда `1.70 mas`, power `0.842`;
- на опубликованном периоде `94.864 ч`: амплитуда `3.69 mas`, power `0.818`;
- глобальная bootstrap FAP максимума по 10 000 реализациям: `4.55%`.

Пик около 95 часов присутствует, но рядом имеется более высокий приблизительно
двукратный алиас. Спектральное окно вблизи 95 часов само имеет большую мощность
около `0.80`, поэтому выборка сильно предрасположена к такому пику, а значимость
пока недостаточна для подтверждения двойственности.
Отдельно нужно проверить спектральное окно, устойчивость к орбитальной модели,
числу транзитов и модели эмпирических ошибок.

Положение наземной серии пересчитано относительно той же FPR/ASSIST-орбиты с
дифференциальным солнечным отклонением света:
`O−C = (+39.83, +37.16) mas`. Наблюдения сделаны на станции Assy-Turgen
(MPC 217); термин «пулковские» здесь обозначает происхождение набора, а не
географическую площадку Пулково.

### 2. Промежуточная локальная редукция серии

В `series_reduction.ipynb` обработаны все 98 R-кадров 2025-09-03:

- выбраны 8 одинаковых локальных звёзд, одна нестабильная звезда исключена;

- медианный RMS локальной Gaia-привязки равен `115.8 mas`;

Этот вариант оставлен как исходная точка сравнения. В нём одни и те же звёзды
используются для локальной модели и оценки её качества.

### 3. Локальная двухзонная коррекция

Основная обработка находится в `two_zone_stacking.ipynb`.

Принята следующая схема:

1. Внешние звёзды задают линейную привязку `(x,y) → (ξ,η)` к Gaia DR3 на каждом
   исходном кадре.
2. Внутренние контрольные звёзды не входят в эту модель.
3. Для внутренних звёзд вычисляется `O−C = измеренное − Gaia`.
4. Среднее O−C считается локальной систематической ошибкой кадра и вычитается
   из положения астероида.
5. Horizons используется только для начального положения и сдвигов при
   сложении, а не для задания измеренного центра.
6. Положения независимых стеков описываются линейной функцией времени; координата
   серии относится к её центральному моменту.

В статье внутренняя граница равна 3 угловым минутам. Для нашего поля проверены
границы 3, 3.5, 4, 4.5 и 5 минут. При 3 минутах доступны только четыре
контрольные звезды. Принята граница 4 минуты:

- внутренняя контрольная зона: `r < 4′`, 11 звёзд;
- внешнее калибровочное кольцо: `4′ ≤ r < 10′`, обычно измеряются 23–25 звёзд;
- медианное число использованных внешних звёзд после робастного исключения — 21;
- медианный двумерный RMS внешней модели — `123.7 mas`.

Группы внутренней и внешней зон строго не пересекаются.

### 4. Отбраковка кадров

Плохие кадры исключаются до измерения астероида только по внешним звёздам:

```text
предел = median(внешний RMS) + 3 × 1.4826 × MAD
```

Для текущей серии предел равен `187.6 mas`; исключены 6 из 98 кадров. Остатки
астероида не участвуют в отборе, поэтому RMS нельзя искусственно уменьшить
удалением неудобных положений объекта.

### 5. Размер стеков

Проверены группы по 8, 10, 12, 15, 18, 20 и 25 исходных кадров. Выбраны группы
по 20 кадров:

- получаются пять независимых стеков;
- после отбраковки в них остаётся 20, 19, 20, 17 и 16 кадров;
- медианная длительность одного стека — около 4.1 минуты;
- ожидаемое движение за это время — около `0.73″`, или 1.5 пикселя;
- движение компенсируется `shift-and-add`;
- измеренная FWHM при переходе от 10 к 20 кадрам не увеличилась;
- медианный S/N вырос примерно до 12.

### 6. Эмпирическая звёздная PSF

Для каждой группы строится отдельная PSF по звёздам тех же кадров:

- радиус отбора относительно астероида — 8 минут;
- диапазон блеска — `14.5 < G < 16.5`;
- насыщенные и слишком слабые изображения исключаются;
- фон вычитается, центры совмещаются с субпиксельной точностью;
- изображения нормируются по потоку и объединяются с sigma-clipping;
- в одной PSF используется примерно 360–480 звёздных изображений.

При подгонке астероида форма PSF фиксирована; свободными остаются фон, поток и
два смещения. Для контроля на тех же стеках подбирается двумерная гауссиана с
двумя дополнительными свободными ширинами.

Подготовлен отдельный учебный `psf_simple_examples.ipynb`, визуально показывающий
идеальную точку, PSF, seeing, построение PSF по звёздам, подгонку слабого объекта
и действие shift-and-add.

## План дальнейшей работы

### A. Единый скрипт серии

`configs/20250903_R.toml` является единым источником параметров. Функция
`reduce_series(config)` и скрипт `reduce_ground_series.py` выполняют весь цикл:
WCS-FITS → покадровая двухзонная привязка → контроль качества → shift-and-add →
PSF → итоговые таблицы. `build_ground_series.py` собирает из них одну строку с
полной ковариацией ξ/η, S/N, числами кадров и стеков и машиночитаемыми флагами
качества. Центральная координата и ковариация получаются совместным двумерным
fit по парным остаткам стеков.

Чистые операции измерительного слоя вынесены в `ground.py`: чтение FITS,
время середины экспозиции, Gaia на эпоху, касательная плоскость, центры звёзд,
робастная аффинная модель и построение/подгонка PSF. Полный повторный запуск дал
точное совпадение всех числовых CSV с вариантом до рефакторинга.

Перенос Gaia теперь учитывает `pmra/pmdec`, положительный физически допустимый
параллакс, перспективное ускорение при наличии лучевой скорости и
топоцентрическое положение станции 217. Для шумных почти нулевых параллаксов,
дающих нефизическую поперечную скорость, сохраняется явный линейный fallback.
На лучшей серии точная модель сдвинула результат лишь на `1.2/0.3 mas`: она
необходима для корректности, но не является источником нынешних 30-mas систематик.

Ноутбук сокращён до отчётного слоя и вызывает ту же `reduce_series(config)`, что
и командный скрипт. Полный запуск ноутбука и CLI дал побайтно одинаковые шесть
выходных CSV для основной ночи.

Для `20250902` построены bootstrap-WCS по перекрывающемуся звёздному полю
`20250903`. Это не независимый blind solve: переносится геометрия той же камеры,
а покадровый сдвиг находится корреляцией; окончательная аффинная модель заново
оценивается по Gaia. Из 20 кадров принят 19. Прежний отказ QC был артефактом
разбиения на шесть слишком слабых стеков и peak-pixel S/N. Полный
motion-compensated стек даёт fitted S/N `29.89` и уверенное изображение объекта.
Odd/even половины расходятся на `265 mas`, поэтому итоговые ошибки расширены до
`88/128 mas`. Серия включена в совместный fit с малым весом.
Leave-one-frame-out проверка даёт медианное/максимальное изменение `31/76 mas`.
Аномальный по локальным звёздам первый кадр меняет итог всего на `15 mas`, а
прямой покадровый fit проваливает проверки PSF и loss (`217/123 mas`). Поэтому
нет одного объективного звёздного QC-критерия, удаление которого исправило бы
эту серию; ограничение задают слабый объект и нестабильная PSF.

99 Hα-кадров `20250903` обработаны, принято 94. Локальный слепой fit полного
стека даёт S/N `9.06`, но в неверном месте и не повторяется в четвертях серии.
Forced photometry в положении, перенесённом из R, даёт S/N `6.19`. Во время
серии астероид приближается к Gaia-звезде G≈14.65 с `15.7″` до `12.2″`; её крыло
дополнительно мешает глобальному фону. Hα сохраняется как необнаружение/верхний
предел потока, но не как фиктивная координата.

Для десяти R-кадров `20251010` загружен отдельный каталог из 600 Gaia-источников
и построен bootstrap-WCS нового поля. Геометрия камеры взята с решённого
сентябрьского кадра, начальный центр — из координат наведения FITS, а остаточный
сдвиг первого кадра найден корреляцией Gaia и наблюдаемого звёздного рисунка;
следующие кадры связаны по перекрытию. Обнаруженный при разработке перенос
сентябрьской `MJD-OBS` исправлен: WCS переносит только геометрию, а временные
ключи всегда сохраняются от целевого FITS.

Все 10 кадров прошли звёздную покадровую отбраковку. Найдена ошибка прежней
обработки: округлённое наведение сочеталось с нулевой скоростью и узким поиском.
После подстановки FPR/ASSIST-скорости `(−22.67,−15.20) arcsec/hour` полный
стек даёт fitted S/N `44.66`; источник находится рядом с FPR-прогнозом и не
совпадает с Gaia-звездой. Split-half расхождение `227 mas` расширяет ошибки до
`116/42 mas`; серия включена в общий ряд с этим весом.
Два исходных блока по пять кадров разделены перенаведением примерно на `40 px`;
их независимые центры расходятся на `181 mas` при S/N `30.7/32.6`. Локальные
контрольные звёзды также меняются между блоками на медианные `57 mas`, но шести
звёзд недостаточно для надёжной карты поправок. Это объясняет расширенную
ошибку как сочетание малого числа кадров, локальной PSF и смены положения на
детекторе, а не как сбой sigma-clipping.

### B. Поиск и измерение слабого астероида

1. Эфемерида задаёт только область поиска и начальную скорость; измеренный центр к ней
   не принуждается. Для `20250903_R` это реализовано прямой подгонкой пикселей
   относительно близкой Gaia-звезды.
2. Совместный линейный forward fit всех 92 принятых кадров с общими положением и
   скоростью и отдельными фоном и потоком выполнен. Покадровые PSF построены по
   23–24 звёздам. Получено `O−C = (−21.64, +26.56) mas`, формальные ошибки
   `19.1/21.3 mas`; независимая опорная звезда отличается на `17.48 mas`.
   Групповая PSF даёт положение на `34.03 mas` дальше, а альтернативный
   робастный fit — на `3.61 mas`. Обе разницы включены в итоговую ковариацию
   (`32.1/31.0 mas`). Ускорение астероида не добавлялось, поскольку оно
   ещё не прошло бы независимую звёздную кросс-проверку.
   Та же смена PSF относительно второй близкой Gaia-звезды даёт `14.36 mas`;
   направления двух векторов почти одинаковы (`cos=0.993`), но их разность
   равна `19.83 mas`. Поэтому PSF-сдвиг нельзя считать известной общей поправкой
   и вычитать для искусственного уменьшения ошибки.
3. Покадровая диагностика seeing и атмосферы выполнена. FWHM меняется на
   `0.88 px`, но значимой корреляции с локальными остатками или RMS привязки не
   найдено (`|r|<0.11`). DCR по этой серии неидентифицируема: `tan(z)` и время
   имеют корреляцию `−0.99955`. Поправка не применялась; нужны серии с большим
   диапазоном часового угла и/или наблюдения стандартов разных цветов.
   Звёздный fit с фиксированными эффектами источников и кадров подтвердил эту
   неидентифицируемость: `793 ± 592 mas` на единицу `BP−RP` и `tan(z)` при
   диапазоне `tan(z)=0.632–0.700`; такую поправку применять нельзя.
4. `Shift-and-add` используется для накопления сигнала слабого объекта. Адаптивное
   деление выполнено: `20250903_R` даёт 12 значимых подстеков, `20250902_R` — три
   значимых подстека до длинного разрыва, `20251010_R` — три значимых подстека на
   слишком коротком для скорости интервале. Число кадров выбирается по заранее
   заданному S/N и допустимому временному разрыву, а не по остаткам астероида.
5. Смещение и полнота обнаружения проверены инъекцией искусственной PSF того же
   потока и скорости в реальные кадры до интерполяции, clipping и сложения. Для
   восьми положений каждой R-серии полнота равна 100%; RMS ξ/η составляет
   `77/88`, `19/22` и `90/35 mas` для трёх ночей по времени. Выборка из восьми
   положений дополнена сеткой ожидаемых S/N `4–40`. На уровне 8 обнаружено
   `1/8`, `0/8`, `1/8`, а на уровне 12 — `8/8`, `7/8`, `8/8` для трёх ночей.
   Таким образом, операционный порог fitted S/N=8 нельзя отождествлять с
   ожидаемым S/N до фактической обработки. Для оценки хвостов распределения всё
   ещё нужен более крупный Monte Carlo по радиусу и фазе субпикселя.
6. Шумовой бюджет проверен непосредственно по соседним FITS-кадрам. Для
   `20250903_R` временной шум равен примерно `461 ADU/pixel`, FWHM PSF —
   `5.57 px`, эффективная гауссова шумовая площадь — `70 px²`. Покадровый S/N
   `6.84` корректно накапливается до `68.4` за 92 кадра. Для Hα forced-поток в
   16 раз меньше R, а PSF шире до `7.67 px`; это объясняет forced S/N `6.19`.
   Следующая серия должна экспериментально сравнить экспозиции 5/15/30 секунд
   при одинаковом полном времени и контроле насыщения.
7. Независимые bias, dark и flat отсутствуют; это теперь явно зафиксировано в
   конфигурациях и диагностической таблице. Стабильный крупномасштабный рисунок
   фона имеет RMS порядка `4–5%` в сентябре и `1.2%` в октябре, но локальная
   линейная плоскость меняет шум в кольце астероида менее чем на `1%` по
   сравнению с постоянным фоном. Поэтому пропущенный локальный градиент не
   объясняет низкий S/N. Self-flat из недизерингованных научных кадров применять
   нельзя; абсолютная фотометрия и точность существенно лучше `30–100 mas`
   остаются неподтверждёнными.

### C. Карта дисторсии

1. После аффинной Gaia-привязки каждого кадра накапливать звёздные векторы
   остатков `(delta_xi, delta_eta)` в координатах детектора.
2. Сравнить векторную сетку (робастная медиана в ячейке, минимум независимых звёзд/кадров,
   сглаживание, карта неопределённости) с низкопорядковой B-spline/полиномиальной поверхностью.
   Модель выбирать только по звёздам.
3. Зафиксировать нулевые аффинные моды карты, чтобы она не вырождалась с покадровыми
   сдвигом, поворотом и масштабом.
4. Отдельно проверить зависимости от фильтра, Gaia BP−RP, блеска, FWHM, зенитного расстояния
   и направления на зенит, чтобы отделить статическую дисторсию от дифференциальной рефракции.
5. Оценивать карту на training-кадрах, а качество - на отложенных целых кадрах/ночах.
   При одинаковом положении звёзд ошибка каталога и дисторсия неразделимы, поэтому нужны
   дизеринг или калибровочные поля.

### D. Координата серии и O−C

1. Для 20–30-минутной серии брать положение линейной модели в центральный момент, а не простое
   среднее координат. Ошибку оценивать по ковариации fit, block-bootstrap и псевдоастероидам -
   контрольным звёздам схожего блеска.
2. Нельзя независимо обнулять O−C каждой ночи: это поглотит искомое межночное колебание.
3. Ответы Horizons сохранять только как независимый контроль. Основная эфемерида
   теперь строится единой FPR/ASSIST-орбитой для Gaia и станции 217. Совместная
   шестипараметрическая подгонка 74 Gaia-транзитов и прошедшего QC аппульсного
   положения выполнена без свободного сдвига ночи. Она оставляет наземный остаток
   примерно `(−23.6, +42.4) mas` и почти не меняет FPR-состояние, поскольку ошибка
   орбиты на этой эпохе (`1.35/0.29 mas`) меньше формальной ошибки наземной точки.
   Следующий содержательный шаг — добавить независимые качественные ночи, а не
   усложнять модель по одной эпохе.
4. Таблица для орбитального fit строится явно по правилу «одна серия — одно
   измерение». Для `20250903_R` аппульсный forward fit заменяет измерение полного
   стека, а не добавляется рядом с ним: эти оценки получены из тех же 92 кадров
   и не являются независимыми. Две остальные R-ночи пока представлены полными
   стеками.

### E. Периодограмма

1. Весовая GLSP сравнивает `общая O−C-поправка + тренд` с `поправка + тренд + синус`,
   с учётом полной двумерной ковариации.
2. Заранее разделить подтверждающий поиск вокруг `94.864 ± 1.81 ч` и слепой широкополосный поиск.
   Для них разные поправки на поиск по многим частотам.
3. Всегда строить спектральное окно; оценивать значимость и интервалы Monte Carlo, block-bootstrap по ночам
   и injection-recovery сигнала 8 mas на реальных моментах и ошибках.
4. До набора достаточной выборки периодограмма - только диагностика. Вывод о двойственности
   требует воспроизведения периода на независимых ночах, контроля алиасов и ложных тревог.

## Правила для кода

- Один notebook решает один понятный этап.
- Ячейки выполняются сверху вниз.
- Параметры анализа задаются в начале.
- Код остаётся линейным и читаемым, без скрытых конвейеров и лишних классов.
- Производные таблицы сохраняются в `outputs/`, который не входит в Git.
- Отбор кадров и звёзд не должен использовать остатки астероида.
