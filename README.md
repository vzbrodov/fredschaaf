# Астрометрия астероида (7065) Fredschaaf

Небольшой учебный репозиторий для первых шагов обработки наблюдений
астероида (7065) Fredschaaf.

## Что лежит в репозитории

- `Fredschaaf/` — исходные FITS-кадры, разложенные по датам;
- `exam/` — исходный учебный пример;
- `reductions.ipynb` — простая астрометрическая привязка одного кадра;
- `series_reduction.ipynb` — локальная редукция и стеки полной серии реальных кадров;
- `papers/` — три статьи по теме;
- `PROJECT_PLAN_RU.md` — текущая стадия и ближайшие действия.

Производные таблицы, стеки и кэш в Git не сохраняются.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./run_jupyter.sh
```

Откройте `reductions.ipynb` и выполняйте ячейки сверху вниз. Notebook:

1. открывает WCS-решённый кадр из `exam/`;
2. читает сохранённую выборку реальных звёзд Gaia DR3 из `exam/gaia_dr3_field.csv`;
3. переносит их координаты на эпоху кадра;
4. измеряет центры звёзд;
5. выбирает локальную сетку звёзд вокруг астероида;
6. сравнивает линейную привязку по всему полю и по локальной сетке;
7. показывает остатки и СКО в mas.

Каталог был заранее получен из Gaia Archive для поля тестового кадра, поэтому
пример работает без сети. Для нового поля сначала нужно один раз выгрузить новую
выборку Gaia по центру кадра и сохранить её в CSV.

## Откуда брать реальные данные

- изображения уже находятся в `Fredschaaf/<дата>/*.fits`;
- координаты опорных звёзд берутся из Gaia DR3;
- ожидаемое положение и скорость астероида на момент кадра берутся из JPL
  Horizons для кода обсерватории `217`.

Файл `exam/gaia_dr3_field.csv` — реальная выборка Gaia DR3 для тестового кадра
`exam/Fredschaaf_R.fits`. В нём сохранены идентификаторы звёзд, координаты,
собственные движения, эпоха и звёздная величина. Для другого поля нужно сделать
такую выгрузку один раз, после чего редукция снова выполняется полностью локально.

Это абсолютная привязка и стартовая проверка данных.

Для обработки серии откройте `series_reduction.ipynb`. Он использует все 98
R-кадров 2025-09-03, строит усреднённую локальную систему по ближайшим звёздам,
отбраковывает нестабильные опорные звёзды и складывает кадры независимыми
группами по 10. Центр астероида на каждом стеке определяется двумерной
гауссовой моделью. Итоговые таблицы сохраняются в `outputs/`.

## Статьи

- `papers/S003809462470031X.pdf` — измерение координат относительно локальной сетки;
- `papers/1-s2.0-S0032063321000842-main.pdf` — относительная астрометрия по Gaia;
- `papers/2406.07195v2.pdf` — поиск астрометрического сигнала двойного астероида.
