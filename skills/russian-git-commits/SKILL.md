# Коммиты на русском

Сообщение коммита пиши на русском: кратко, конкретно и в прошедшем времени от первого лица.

Примеры: `Добавил проверку WCS`, `Исправил расчёт центрального времени`.

Не используй неопределённые формулировки вроде «Правки» или «Обновления».
