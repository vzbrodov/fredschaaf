# Коммиты на русском

Сообщение коммита пиши на русском: кратко, конкретно и в повелительном наклонении.

Примеры: `Добавь проверку WCS`, `Исправь расчёт центрального времени`.

Не используй неопределённые формулировки вроде «Правки» или «Обновления».
